Panduan Pengguna
SI JIMITIUS

Petunjuk singkat untuk memudahkan semua role dalam menggunakan sistem.

🎯 Tujuan Aplikasi

SI-JIMITIUS membantu mengelola jadwal, monitoring kegiatan, dan dokumen secara cepat, rapi, dan transparan.

🖥️ Persyaratan Sistem

  • 💻 Laptop/PC atau smartphone modern
  • 🌐 Internet stabil minimal 3 Mbps
  • 🔑 Akun resmi dari Operator

🚪 Cara Mengakses

Buka alamat aplikasi di browser.

Klik tombol Login.

Masukkan username & password.

Akses dashboard sesuai peran Anda.

👥 Peran & Tugas

Koordinator UKM

Mengatur jadwal kegiatan UKM, memverifikasi laporan, dan memastikan program berjalan sesuai rencana.

Keuangan

Mengelola anggaran, laporan keuangan, serta memantau realisasi dana kegiatan UKM.

Admin TU

Mengelola surat, dokumen resmi, serta memastikan administrasi digital tetap rapi.

Kepala UPT

Melakukan pengawasan, memberi persetujuan, serta evaluasi kinerja seluruh unit.

Operator

Membuat akun, memberikan akses user, serta membantu troubleshooting teknis.

PJ Program

Bertanggung jawab atas keberlangsungan program, serta menyusun laporan akhir.

🧭 Navigasi Utama

Dashboard: ringkasan sesuai role.

Jadwal Bulanan: filter & unduh jadwal UKM.

Monitoring: laporan mingguan UKM.

Surat Tugas & SPPD.

Laporan Anggaran (khusus role).

Pengaturan user & data UKM.

⚠️ Troubleshooting

Tidak bisa login? Hubungi Operator untuk reset akun.

Jadwal kosong? Pastikan file sudah diunggah UKM.

Tampilan error? Reload atau update browser.
